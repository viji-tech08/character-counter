# Real-Time Character Counter

## About the Project

The Real-Time Character Counter is a simple web project built using HTML, CSS, and JavaScript.

It allows users to type a message and displays the number of characters entered in real time. It also shows the remaining characters and displays a warning when the character limit is reached.

## Features

- Real-time character counting
- Maximum limit of 200 characters
- Displays the remaining character count
- Warning message when the character limit is reached
- Simple and user-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open https://viji-tech08.github.io/character-counter/ using Live Server.
4. Start typing in the text area to see the character counter in action.
